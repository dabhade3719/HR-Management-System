# HR-Management-System

🏢 HR Management System (HRMS)

📌 Project Overview

The HR Management System (HRMS) is a web-based application developed using Python and Django. The main purpose of this project is to simplify and manage human resource activities efficiently. It helps manage employee information, attendance, leave applications, and other HR-related operations through a user-friendly interface.

The system provides an organized platform to manage employee records and improve the efficiency of HR activities.

🎯 Objectives

- To simplify human resource management activities.
- To maintain employee records digitally.
- To reduce manual paperwork.
- To manage employee attendance and leave requests.
- To provide an easy-to-use interface for HR operations.
- To improve data organization and accessibility.

⚙️ Installation and Setup

Step 1: Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Navigate to Project Folder

cd HR_Management_System

Step 3: Install Django

pip install django

Step 4: Apply Database Migrations

python manage.py makemigrations
python manage.py migrate

Step 5: Run the Development Server

python manage.py runserver

Step 6: Open in Browser

http://127.0.0.1:8000/
